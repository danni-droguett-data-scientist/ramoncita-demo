# Ramoncita — Restaurant Ops Dashboard (Demo)

A mobile-first demo dashboard for restaurant management — the kind of at-a-glance panel
an owner checks daily. The name plays on *"tu local en la palma"* (your place in the
palm of your hand).

**Language / Idioma:** English | [Español](README.es.md)

**🔗 Live demo:** https://ramoncita.vercel.app

---

## What it shows

- **Sales** — last 14 days and by channel (dine-in / takeaway / delivery)
- **Demand by hour** — for staffing and production planning
- **Prime cost** — what the sale eats (food + labor)
- **Menu engineering** — stars vs. dogs, where the margin goes
- **Fixed monthly costs** and **daily close**
- **Productivity**

Built as a portfolio piece to show how operational and financial KPIs for a restaurant
can be surfaced in a single, phone-friendly view.

## Tech

Single self-contained `index.html` (HTML / CSS / JavaScript). No build step, no backend.

## Run

Open `index.html` in a browser, or deploy the folder to any static host
(GitHub Pages, Vercel, Netlify).

> Demo with **illustrative data** — not a real business.
