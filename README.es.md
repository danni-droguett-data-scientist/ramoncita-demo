# Ramoncita — Panel de Gestión para Restaurantes (Demo)

Un panel *mobile-first* de gestión para restaurantes — de esos que un dueño revisa a
diario de un vistazo. El nombre juega con *"tu local en la palma"* (de la mano).

**Language / Idioma:** [English](README.md) | Español

**🔗 Demo en vivo:** https://ramoncita.vercel.app

---

## Qué muestra

- **Ventas** — últimos 14 días y por canal (local / para llevar / delivery)
- **Demanda por hora** — para planificar turnos y producción
- **Prime cost** — lo que se come la venta (insumos + mano de obra)
- **Menu engineering** — estrellas vs. perros, dónde se va el margen
- **Gastos fijos del mes** y **cierre del día**
- **Productividad**

Hecho como pieza de portafolio para mostrar cómo los KPIs operativos y financieros de
un restaurante se pueden ver en una sola pantalla pensada para el celular.

## Stack

Un solo `index.html` autocontenido (HTML / CSS / JavaScript). Sin build, sin backend.

## Cómo correr

Abre `index.html` en un navegador, o publica la carpeta en cualquier hosting estático
(GitHub Pages, Vercel, Netlify).

> Demo con **datos ilustrativos** — no es un negocio real.
